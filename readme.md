
# Deserv HNI Portfolio Analysis








## The Case




A 42-year-old HNI has ₹3.50 Cr to invest.

He has a 10+ year investment horizon.

He also expects to need ₹20 lakh within the next 3 years.

His risk profile is moderate-aggressive.

The portfolio needs to balance long-term growth with this near-term cash requirement.






## The Question



Is the current portfolio suitable for the client's goals?

The analysis looks at the portfolio's:

- Allocation
- Performance
- Risk
- Concentration
- Liquidity
- Rebalancing needs






## What Was Analysed


The portfolio was broken down investment by investment.

The analysis then looked at how the holdings behave as a portfolio rather than as separate investments.

This includes : 

- portfolio performance, 
- risk measures, 
- concentration, 
- liquidity and 
- portfolio-level gaps.







## The Output




### Excel

The Excel workbook contains the detailed calculations and analysis behind the project.

It includes the portfolio data, calculations, risk analysis, performance analysis, rebalancing analysis and recommendations.




### Power BI

The Power BI dashboard gives a quick view of the portfolio.

It covers:

- Portfolio allocation
- Performance
- Risk
- Concentration
- Liquidity
- Key portfolio observations
- Recommended actions






## The Decision

The final part of the analysis turns the numbers into actions.

It identifies where the portfolio is outside the client's requirements and what changes could be considered.
